# Impulso Digital

Projeto desenvolvido como Atividade Extensionista do curso de Ciência da Computação da GRAN Faculdade.

## Objetivo

Fornecer suporte tecnológico e orientação digital para profissionais liberais, como advogados, psicólogos, contadores, médicos, arquitetos e outros prestadores de serviços.

## Publicação

Site: https://auricongomes.github.io/impulso-digital/

- `index.html`: página canônica, renomeada de `microempreendedores` sem alteração de conteúdo.
- `preview(13).html`: referência histórica; não é incluída no artefato de publicação.
- `.github/workflows/static.yml`: publica apenas `index.html` e `.nojekyll` no GitHub Pages a cada push em `main` ou execução manual.
- `.nojekyll`: indica conteúdo estático sem processamento Jekyll.

Em Settings → Pages, a origem deve ser **GitHub Actions**. O resultado de cada publicação pode ser acompanhado na aba Actions, no workflow “Publish landing page to GitHub Pages”.

A página usa CSS e JavaScript embutidos; as âncoras internas funcionam também no subdiretório `/impulso-digital/`. Não há processo de build ou dependências externas locais.
